# ToolBar 产品需求文档（PRD）

## 1. 产品概述

ToolBar 是一款 macOS 菜单栏常驻的极简效率工具，形态对标 Spotlight / Raycast。核心交互一句话：

> 全局快捷键 → 弹出输入框 → 输入命令 → 结果显示 → 自动复制到剪贴板 → 浮层自动消失。

定位：**程序员专用计算器**。不需要后端、不需要联网、不需要账号。

### 目标用户

- 后端 / 客户端开发工程师，日常频繁处理时间戳、JSON、URL 编码、分表计算、IP 转换等琐事。

### 产品价值

- 把「打开浏览器 → 找在线工具 → 粘贴 → 复制」的 30 秒流程压缩到 2 秒。
- 离线、轻量、无打扰，用完即走。

## 2. 产品形态

- 常驻后台运行，**无主窗口、无 Dock 图标**（LSUIElement）。
- 通过全局快捷键唤起一个无边框浮层输入框。
- 默认全局快捷键：**⌃⌥Space**（⌥⌘Space 与系统搜索冲突），支持用户自定义。
- 输入命令并回车后，浮层切换为结果视图：
  - 结果显示约 **2 秒**后浮层自动关闭。
  - 成功结果**自动复制到剪贴板**；错误结果**只显示、不复制**。
- 菜单栏图标提供入口：Settings… / Quit。

## 3. 功能需求

### 3.1 命令一览

| 命令 | 输入示例 | 输出示例 | 说明 |
|---|---|---|---|
| `t` | `t 1756216800` | `2025-08-26 22:00:00`（Asia/Shanghai 时区下） | 时间戳 ↔ 时间字符串，双向转换 |
| `t` | `t 2025-08-26 22:00:00` | `1756216800`（Asia/Shanghai 时区下） | 时间字符串转秒级时间戳 |
| `db` | `db 123456 128` | `table: 40` | 分表计算（规则见 3.4） |
| `ip` | `ip 12345678` | `0.188.97.78` | 整数转 IPv4 点分 |
| `ip` | `ip 10.1.2.3` | `167838211` | IPv4 点分转整数（大端序） |
| `en` | `en https://a.com/a b` | `https%3A%2F%2Fa.com%2Fa%20b` | URL Encode |
| `de` | `de https%3A%2F%2Fa.com` | `https://a.com` | URL Decode |
| `u` | `u https://a.com/a?a=b&c=d` | 美化后的多行 JSON | 解析 query 为 JSON |
| `j` | `j {"a":"b"}` | 格式化后的多行 JSON | JSON 美化 |

### 3.2 `t` 命令（双向转换）

- 输入为整数（Unix 秒级时间戳）→ 输出 `yyyy-MM-dd HH:mm:ss` 时间字符串。
- 输入为 `yyyy-MM-dd HH:mm:ss` 等时间字符串 → 输出秒级 Unix 时间戳（纯数字）。**不严格限制单一格式**，常见格式均可：`yyyy-MM-dd HH:mm:ss`、`yyyy-MM-dd HH:mm`、`yyyy-MM-dd'T'HH:mm:ss`、`yyyy-MM-dd`、`yyyy/MM/dd HH:mm:ss`、`yyyy/MM/dd` 等；兜底用系统自然语言日期识别（如 `2025年8月26日 22:00`，需整串匹配）。
- 时区规则（两个方向均生效）：
  - **默认跟随系统时区**（System Default），不硬编码任何时区。
  - 设置中可切换：System Default / UTC / Asia/Shanghai / America/Los_Angeles 等。
- 只支持秒级时间戳，不支持毫秒；时间字符串格式见上面的列表与自然语言兜底。
- 非法输入输出错误：`Invalid timestamp`。
- 金标示例（双向）：
  - UTC 时区：`t 1756216800` → `2025-08-26 14:00:00`；`t 2025-08-26 14:00:00` → `1756216800`
  - Asia/Shanghai 时区：`t 1756216800` → `2025-08-26 22:00:00`；`t 2025-08-26 22:00:00` → `1756216800`

### 3.3 `ip` 命令

- 输入为纯数字 → 输出点分 IPv4（`a.b.c.d`）。
- 输入为点分 IPv4 → 输出 32 位无符号整数。
- 非法输入输出错误：`Invalid IP`。

### 3.4 `db` 命令（规则已定死）

输入格式：`db <值> <分表数>`。

值的三种形态：

- **纯数字**（如 `db 123456 256`）→ 直接 `值 % 分表数`。
- **非数字字符串**（如 `db abcdefg 256`）→ 对值的 UTF-8 字节做 **CRC32**（标准 CRC-32，与 zlib 一致），再 `CRC32 % 分表数`。
- **加双引号**（如 `db "123456" 256`）→ 强制按字符串处理（CRC32），引号内允许空格。

输出格式：

- 分表数为 **2 的幂**（2、4、8、16、32、64、128、256…）→ 输出 **十六进制**：小写、**无 `0x` 前缀**，按 `分表数 - 1` 的十六进制位数**左侧补 0**：
  - 分表 16 → 1 位（`0`–`f`）：`db 11 16` → `11 % 16 = 11` → `table: b`
  - 分表 64 / 128 / 256 → 2 位（`00`–`ff`）：`db 123456 128` → `123456 % 128 = 64` → `table: 40`
- 分表数为 **十进制数**（10、100…）→ 输出 **十进制**：
  - `db 123456 100` → `123456 % 100 = 56` → `table: 56`
- 其他分表数（如 3、7）按十进制输出。
- 非法输入输出错误：`Invalid db arguments`（缺少分表数、分表数非正整数、引号未闭合等）。
- 复制到剪贴板的内容仅为值本身（如 `40`），不含 `table: ` 前缀。

字符串示例：

- `db abcdefg 256` → `crc32("abcdefg") = 824863398`，`824863398 % 256 = 166` → `table: a6`
- `db "123456" 256` → `crc32("123456") = 158520161`，`158520161 % 256 = 97` → `table: 61`（对比 `db 123456 256` 直接取模得 `table: 40`）

> 说明：原始文档指出分表算法存在多种可能（取模 / 整除 / hash）。本 PRD 规定：数字取模，字符串走 CRC32 取模，双引号强制按字符串。

### 3.5 `en` / `de` 命令

- `en`：对参数整体做 URL Percent-Encoding。**规则定死：除 RFC 3986 unreserved 字符（字母、数字、`-`、`.`、`_`、`~`）外全部编码**，即 `:`、`/`、空格等均编码：
  - `en https://a.com/a b` → `https%3A%2F%2Fa.com%2Fa%20b`
- `de`：对参数做 Percent-Decoding：
  - `de https%3A%2F%2Fa.com` → `https://a.com`
- 解码失败输出错误：`Invalid encoded string`。

### 3.6 `u` 命令

- 使用 Foundation `URLComponents` 解析 query。
- 输出**美化格式（2 空格缩进）的多行 JSON**，与 `j` 命令同一套序列化规则（不转义非 ASCII、不转义 `/`）：
  - 普通参数 → `{"a":"b","c":"d"}` 的展开多行形式
  - **重复参数名合并为数组**：`?a=1&a=2` → `{"a":["1","2"]}` 的展开多行形式
- 结果视图按多行展示，剪贴板写入美化后的 JSON。
- 无 query 或解析失败输出错误：`Invalid URL`。

### 3.7 `j` 命令

- 输入任意合法 JSON 字符串，输出 2 空格缩进的格式化 JSON。
- **不转义非 ASCII 字符**：汉字正常显示（`"张三"` 而不是 `"\u5f20\u4e09"`）。
- 复制到剪贴板的就是格式化后的 JSON，不是转义后的字符串。
- 结果视图支持多行展示。
- 非法输入输出错误：`Invalid JSON`。

### 3.8 错误处理

| 场景 | 显示 |
|---|---|
| 命令不存在（`xxx abc`） | `Unknown command` |
| 参数非法 | 各命令对应错误文案（见上文） |

- 错误只在浮层中显示，**不写入剪贴板**。
- 错误浮层同样约 2 秒后自动关闭（或 Esc 立即关闭）。

### 3.9 交互细节

- 浮层唤起时自动获得焦点，输入框清空待输入。
- `Enter` 执行命令；`Esc` 直接关闭浮层。
- 输入框支持标准编辑快捷键（⌘V 粘贴 / ⌘C 复制 / ⌘X 剪切 / ⌘A 全选）。
- 普通命令结果显示单行；`j`、`u` 命令显示多行。
- 结果视图附带 `Copied ✓` 提示（仅成功时）。
- 浮层位置：屏幕上方居中（类 Spotlight），当前活跃屏幕。

## 4. 设置项

当前无独立设置页面；**Launch at Login 已实现**：菜单栏勾选开关（SMAppService），默认开启（首次启动自动注册登录项），状态以系统为准（与系统设置 → 登录项联动）。后续迭代加入：

| 设置项 | 默认值 | 说明 |
|---|---|---|
| Global Shortcut | ⌃⌥Space | 全局唤起快捷键，可自定义 |
| Timezone | System Default | t 命令时区 |
| Default DB Format | Auto | db 输出格式（Auto / Hex / Decimal） |
| Launch at Login | 开启 | 开机自启（SMAppService），已实现 |

菜单栏菜单结构：

```text
ToolBar
────────────
Open ToolBar (⌃⌥Space)
Launch at Login ✓
────────────
Quit
```

## 5. 非功能需求

- **离线**：除系统 API 外无任何网络请求。
- **轻量**：常驻内存占用目标 < 50MB，唤起响应 < 100ms。
- **零第三方依赖**：全部使用系统框架（SwiftUI / AppKit / Foundation / Carbon）。
- **兼容性**：macOS 13+（SMAppService 需要 macOS 13）。
- **深色 / 浅色模式**：跟随系统外观。
- **隐私**：不收集任何数据，剪贴板仅由用户命令触发写入。
